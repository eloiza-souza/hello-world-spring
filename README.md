# Hello World Application

Este é um projeto simples usando **Spring Boot** que retorna a frase **"Hello World!"** no endereço `http://localhost:8080`.

## Pré-requisitos

Certifique-se de ter os seguintes itens instalados em sua máquina:

- [Java 17+](https://www.oracle.com/java/technologies/javase-downloads.html)
- [Maven 3.8+](https://maven.apache.org/download.cgi)

## Testando a Aplicação
Após iniciar a aplicação, você pode testar o endpoint acessando o seguinte endereço no navegador ou em uma ferramenta de requisições HTTP:
 http://localhost:8080. 
A resposta será: 

 ```plaintext 
 Hello World!
